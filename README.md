# Einführung in ABAP Core Data Services

Dieses Repository enthält den Beispielcode zur dreiteiligen Online-Kursreihe **„Einführung in ABAP Core Data Services“**.

Ausgehend von einfachen Datenbanktabellen entsteht schrittweise ein zusammenhängendes CDS-Datenmodell für Kunden, Produkte, Aufträge und Auftragspositionen.

## Inhalte

- **Teil 1:** CDS View Entities, Annotationen, Assoziationen, ABAP-SQL-Zugriff und Zugriffskontrolle mit DCL
- **Teil 2:** Code Pushdown mit Ausdrücken, Funktionen, Aggregationen und Unions sowie View und Metadata Extensions
- **Teil 3:** UI-Annotationen für Fiori Elements, analytische CDS Views und Hierarchien

Die Entwicklungsobjekte entsprechen den Live-Coding-Beispielen der Kursreihe und können auch als Ausgangspunkt für eigene Übungen verwendet werden.

## Voraussetzungen

- SAP BTP ABAP Environment oder ein geeignetes aktuelles ABAP-System
- ABAP Development Tools (ADT) für Eclipse
- abapGit für den Import des Repositorys

## Verwendung

Das Repository mit abapGit in ein eigenes ABAP-Paket importieren. Anschließend die Entwicklungsobjekte in der vorgesehenen Reihenfolge aktivieren und die Beispieldaten anlegen beziehungsweise laden.

Der Code dient zu Schulungs- und Demonstrationszwecken.
